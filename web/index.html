Position the tag over the reader. Only writable inventory tags can be edited.

Genuine Bambu Lab and Snapmaker tags are read to identify the spool; they are RSA-signed and cannot be rewritten. A Bambu tag can be copied byte-for-byte onto a Gen2/FUID magic card with Clone a Bambu tag. Printer formats let stock Creality CFS, Anycubic ACE, Elegoo Canvas and Qidi Box firmware recognize the spool; the scale identifies it by the linked tag ID. Bambu Lab and stock Snapmaker U1 tags are RSA-signed and cannot be created. Sovol printers have no tag reader.

Release notes

Filament remaining

Each full LED is 20% of the spool's initial filament weight. A partial LED changes color in 5% steps.

Not available
20%40%60%80%100%

For a 1,000 g refill: 1,000 g lights all five, 600 g lights three, 200 g lights one. Empty-spool weight is subtracted. Below 10%, the remaining segment pulses. Empty pulses red.

Within each 20% segment: the first 5% is red, then orange, yellow, green, and cyan when complete. At 85% the fifth LED is red; at 90% orange; at 95% yellow; at 96–99% green; at 100% cyan. The first four remain cyan.

Blue breathing / chase
Wi-Fi setup / connecting. Double flashes mean offline.
White breathing / cyan breathing
Empty cradle / choose a spool.
Amber moving / double pulse / outer LEDs
Settling / calibration needed / empty-spool weight needed.
Red breathing / alternating
Missing sensor samples / invalid or out-of-range weight.
Purple / blue chase
NFC / saving or Spoolman communication.
Green fill / red double flash
Action succeeded / failed. Normal status returns after 2.5 seconds.

While weighing offline, a brief blue flash on the last LED marks the lost network connection. These tests preserve stored calibration, spool profiles and tag contents.

Calibrate your scale

Zero the empty cradle, add a known weight, then check the reading.

Checking calibration

Waiting for the device.

Pair with the device to calibrate.

  1. 1

    Zero the empty cradle

    Remove the spool and anything resting on it. Leave the cradle, reader and wiring installed, and let everything settle.

    Start here each time you calibrate.

    This sets the scale's zero. It does not change any spool's saved empty weight.

  2. 2

    Add a known weight

    Place a calibration weight, or an object weighed on a trusted scale, on the cradle. Enter its actual weight and keep it still.

    100 to 2,000 g. A spool's nominal filament weight is not a calibration weight.

    Complete step 1 first.

  3. 3

    Check the result

    Remove the reference weight and check that the reading returns near zero. Then compare it with another known weight.

    Not availableg

    A live reading appears after calibration.

    Saving calibration does not verify accuracy. Check repeatability before weighing your spools.

    Back to weighing

Using a compatible 20 kg load cell? Enter the reference object's weight, not the sensor capacity. Recalibrate after changing the cell or mounting. The application's gross spool limit remains 2,000 g.

Add RFID tag

Keep the spool seated and place its tag beside the reader. Scan it, check the tag ID, then link it to this profile.

Scanned tag IDNot scanned

This saves the detected ID on this scale, including for a Spoolman spool. It replaces the previous RFID link without writing to either tag. Read-only printer tags can be linked too.

PN532 supports NFC-A, NFC-B, FeliCa and Jewel IDs, but not NFC Type 5. Cards that change their ID between scans cannot identify a spool reliably. Memory writing is separate: printer formats need an unlocked NTAG213/215/216 or a MIFARE Classic 1K tag, depending on the brand.
