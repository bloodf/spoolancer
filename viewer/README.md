# Spoolancer assembly explorer

A standalone, offline-capable 3D view of the **OLED + five LEDs** and **five LEDs + web controls** enclosures. It uses the actual CAD tessellations, with every printed instance independently selectable, including the two identical cradle rails.

## Open locally

From this folder, run:

```sh
python3 -m http.server 8874 --bind 127.0.0.1
```

Open **http://127.0.0.1:8874/**. A local HTTP server is necessary because browsers restrict module and asset loading through `file://`. No internet connection is needed after downloading the folder. Use a WebGL2-capable browser.

The viewer is also suitable for static hosting such as GitHub Pages. Every asset URL is relative. This folder is a separate desktop/browser deliverable; **do not copy it into the ESP32's web filesystem**.

## Explore

- Drag to orbit, scroll or pinch to zoom, right-drag or two-finger drag to pan. Focus the canvas and use arrow keys to pan.
- Move **Open the assembly** between assembled and exploded positions.
- Select a numbered component or a list entry. Use **Focus**, **Isolate part** or **Hide part** to inspect it.
- **See inside housing** makes the fixed base and lid transparent. Hardware references, the spool, clearance volumes and part numbers have separate toggles.
- **Reset** restores the complete assembled model. **Fit view** frames the visible parts. Standard front, side and top views are available.
- Both light and dark themes work locally; the preference is saved when browser storage is available.

The 12 V-to-5 V converter volume is **unassigned space**, not a selected converter or mounting location. Hardware envelopes remain provisional. Wiring, most fasteners, adhesive and the user-drilled jack are not represented. Exploded offsets illustrate component locations, not a collision-free assembly sequence. Original CAD coordinates are retained at 0% explosion. Flat face shading preserves mechanical edges; the viewer does not smooth or modify the shape.

## Rebuild and verify from the repository

```sh
python3 tools/build_viewer.py
python3 tools/build_viewer.py --check
node viewer/model.test.mjs
```

No FreeCAD installation is needed for these commands. Regenerate CAD scenes first when geometry changes. The builder consumes `cad/variants/{headless-led,oled-led}/previews/scene.json` and the shared `cad/assembly-parts.json` numbering, descriptions and explode offsets. It fails on unmapped meshes, duplicated assignments, missing components, malformed triangles, non-finite coordinates or a changed printed-instance count. `--check` checks exact generated bytes without changing files.

The output pairs in `assets/` contain compact Float32 positions and Uint32 triangle indices, plus source and binary SHA-256 hashes. Float32 conversion introduces only normal floating-point rounding at this scale. CAD STEP and FreeCAD files remain the manufacturing source of truth. All binary arrays use little-endian storage.
