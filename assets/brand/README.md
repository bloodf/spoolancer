# Spoolancer identity

The mark combines an upright filament spool, a weighing platform and NFC arcs. Use the complete mark with enough surrounding space to keep the antenna arcs legible.

| Asset | Use |
| --- | --- |
| [icon.svg](icon.svg) | Editable flat vector mark; source for the local web favicon |
| [icon.png](icon.png) | Original generated raster icon |
| [banner.svg](banner.svg) | Repository header with accessible text description |

Palette: forest green `#073f2e`, warm ivory `#f8f1db`, amber `#ffb52d`. The banner uses system sans-serif fonts; no font files are bundled. These original project assets are distributed under the root MIT license. Manufacturer marks in hardware reference photographs are separate third-party material.

The PNG was created with the built-in image-generation tool. The SVG is a manually authored geometric companion for small sizes and reproducible editing, rather than an exact pixel trace. `web/favicon.svg` is an exact copy of `icon.svg`.

## Raster generation prompt

Use case: logo-brand. Create the primary app icon image for Spoolancer, an open-source DIY filament-spool weighing scale with NFC inventory. This is a brand mark, not a hardware rendering. Square icon, crisp flat vector-like geometry, centered and legible at tiny sizes. A warm ivory circular filament spool viewed face-on with one clear central hole and three broad simple radial slots, seated upright on a minimal horizontal ivory scale platform. A small amber accent on the scale suggests the weighing indicator; two restrained amber NFC arcs in the upper-right of the spool communicate identification. Background is a solid very dark forest-green rounded square, with ample even margins. Match an understated practical maker project: clean continuous curves, sturdy proportions, restrained forest green, warm ivory and amber palette. Exactly one coherent icon. No words, no letters, no numbers, no shadows, no gradients, no 3D, no photographic texture, no mockup device, no watermark, no existing brand symbols. Produce a polished original square PNG suitable as a GitHub README icon and app icon.
