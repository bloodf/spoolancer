# Earlier prototypes

These snapshots record the project's design history. Use the current [build guide](../docs/BUILD-GUIDE.md) and [print manifest](../docs/PRINTING.md) for new builds.

- [v0.1 flat](v0.1-flat/SUPERSEDED.md): original platform layout.
- [v0.2 upright](v0.2-upright/SUPERSEDED.md): full saddle design.
- [v0.3 compact](v0.3-compact/SUPERSEDED.md): earlier display and three-button layout.

Historical dimensions, wiring, tests and status statements describe their own revision. They do not establish physical validation of the current design. Original source/CAD snapshots are preserved; local build logs, CAD autosaves, vendor PDFs and machine-specific slicer work are not distributed.

Historical commands that say “project root” mean the selected revision directory, such as `archive/v0.3-compact/`, not the current repository root. Their macOS tool paths describe the original environment; adapt them for another installation. Use the current CAD guide for new work.
